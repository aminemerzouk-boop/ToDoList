# Daylight

A calm, responsive to-do workspace built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Includes task creation, completion and deletion, project navigation, upcoming tasks, search, status filters, priority sorting, and daily progress. Tasks are saved in browser localStorage. The initial tasks are editable demo data; no account or backend is required.
